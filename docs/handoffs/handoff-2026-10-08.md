## Appendix B — recovering lost information from `/mnt/transcripts`

Each file is a sequence of `Assistant:` / `Content:` blocks, each followed by a JSON array. Parse them instead of grepping (the text is multi-layer escaped):

```python
import json, re
DEC = json.JSONDecoder()
def blocks(path):
    t = open(path, 'rb').read().decode('utf-8', errors='replace')
    for m in re.finditer(r'(?m)^(Assistant|Human|User):\s*\nContent:\s*\n(?=\[)', t):
        try:
            arr, _ = DEC.raw_decode(t, m.end()); yield m.group(1), arr
        except Exception: continue
def tool_uses(path):
    for role, arr in blocks(path):
        if role == 'Assistant' and isinstance(arr, list):
            for b in arr:
                if isinstance(b, dict) and b.get('type') == 'tool_use': yield b
```
This is how `SKILL.md` was recovered: list every `str_replace` on the skill path, then **replay them in order onto the base file**, skipping superseded edits. Verify with independent markers (known line numbers). Never reconstruct from memory when the transcript has the exact text.
